# APU Core v1.5 — CHANGELOG

Status: STABLE/FROZEN

APU Core v1.5 vychází z ověřeného Frozen Core v1.4. Starší releasy zůstávají beze změny.

## Pedagogická změna

- doplněna pravidla Fáze 2 pro živý Rozbor odvozený výhradně ze Zápisníku;
- vymezeny pracovní hypotézy, zacílení podle pedagogických potřeb, limity a doplňující otázky;
- přechod do Fáze 3 zůstává výhradně na explicitním rozhodnutí uživatele.
- karta Rozboru a stručná chatová reprezentace nyní vycházejí z jednoho strukturovaného stavu;
- samostatné hypotézy musejí být rozlišitelné konkrétní informací, otázkou nebo pozorováním, jinak se slučují;
- Fáze 2 je výslovně oddělena od konkrétních doporučení, plánů a hotových výstupů Fáze 3.

## Technická hranice

Technická pravidla, strukturované generování, routing a kontext vybrané položky zůstávají mimo Core v runtime vrstvě aplikace. Knowledge Base nebyla změněna.
