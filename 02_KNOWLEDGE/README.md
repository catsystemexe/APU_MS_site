# 02_KNOWLEDGE

Documentation map for APU knowledge assets.

The versioned APU Core / knowledge material already exists in this repository under `../apu-core/` (`v1.1` through the currently present versions). It is not duplicated here.

This directory preserves the project-documentation taxonomy:

- `KNOWLEDGE_BASE/` — map to the versioned repository knowledge assets.
- `METHODOLOGY/` — methodology material when added.
- `RESEARCH/` — research material when added.
- `CASES/` — case material when added.
- `INBOX/` — non-canonical intake/legacy supporting material.

Do not treat `INBOX` or archived material as active product truth without an explicit decision.
