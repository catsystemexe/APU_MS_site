# 03_APU_SITE

Operational and technical project documentation.

- `CURRENT/` — current technical/runtime state.
- `CHANGELOG/` — verified implemented changes.
- `BACKLOG/` — explicit unfinished/planned work; not a general work log.
- `KNOWN_ISSUES/` — confirmed current issues.
- `DEVLOG/` — Shared Feedback / developer feedback protocol and current feedback source.
- `CHECKPOINTS/` — checkpoint/history references.

Updates follow the `Documentation & Tracking` contract in `05_WORKFLOW/` and are written only after the assigned verification passes.
