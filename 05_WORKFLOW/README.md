# 05_WORKFLOW

Governing APU development workflow documents.

For normal APU implementation, use:

1. `WORKFLOW_CORE.md`
2. exactly one active role document (`DESIGN_ROLE.md`, `INSTRUCTIONS_ROLE.md`, or `IMPLEMENTATION_ROLE.md`)
3. `APU_PROJECT_RULES.md`

The repository copy is canonical for development. Selected workflow files may also be loaded into ChatGPT Project Sources as runtime copies; those copies are not an independent source of truth.
