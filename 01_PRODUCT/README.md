# 01_PRODUCT

Current product-level documentation for APU.

- `ARCHITECTURE/` owns architecture, data-layer boundaries, and supporting roadmaps.

Current documents are authoritative only when their own status marks them as current. Historical material belongs under `04_HISTORY/`.
